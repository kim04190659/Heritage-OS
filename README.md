# Heritage-OS (Heritage Knowledge Archive)

## ビジョン

「地域の記憶を、未来の知性へ。」
自治体職員の暗黙知をデジタル資産化し、異動の壁を越えた行政サービスを実現する。

## 開発・運用ルール

- **基盤層 (Core OS)**: GitHub + NotebookLM連携による情報の構造化と履歴管理。
- **アプリ層 (App Layers)**: 各部局（用地、財政、福祉等）への個別カスタマイズ。
- **役務層 (Professional Services)**: 専門エディターによる伴走型インタビューとリファクタリング。

## ディレクトリ構造

- `/core-os/`: システム基盤定義 (旧 base-platform)
- `/professional-services/`: 役務マニュアル・手法 (旧 excellent-services)
- `/knowledge-assets/`: 実際のナレッジ蓄積 (旧 docs-knowledge)
- `/app-layers/`: 自治体別アプリ層 (旧 apps-local-gov)
