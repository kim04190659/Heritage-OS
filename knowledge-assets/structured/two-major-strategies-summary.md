# 【特集】用地交渉の二大戦略：情緒と合理の統合

## 1. 概要

Heritage-OSに蓄積された事例から、困難な用地交渉を突破するための2つの対照的なアプローチが明らかになりました。
担当者は、地権者のタイプや交渉フェーズに応じて、これらを使い分けることが推奨されます。

## 2. 戦略比較

| アプローチ         | **① 情緒的アプローチ (Emotional)**               | **② 経済合理的アプローチ (Rational)**                      |
| :----------------- | :----------------------------------------------- | :--------------------------------------------------------- |
| **代表事例**       | [仏壇の対話 (Road 305)](./sato-interview-001.md) | [日本橋・合筆戦略 (Nihonbashi)](./land-merger-strategy.md) |
| **ターゲット**     | 先祖代々の土地を守る高齢者、保守層               | 資産活用に関心がある層、合理的判断をする層                 |
| **キーワード**     | 「継承」「家族の安全」「罪悪感の解消」           | 「資産価値最大化」「合筆」「都市再生」                     |
| **刺さる言葉**     | 「お孫さんが安全に帰ってこれますよ」             | 「10年待てば、資産は3倍になって子孫に残せます」            |
| **AI分析 (Logic)** | 信頼関係構築を最優先                             | ゲーム理論的相互利益 (Win-Win)                             |

## 3. 統合戦略：ハイブリッド・ネゴシエーション

熟練の交渉官は、これらを二者択一ではなく**シーケンシャル（順序的）**に使用しています。

1.  **Entry**: まず**戦略①**で信頼関係を築き、相手の「土地への想い」を受け止める。（敵対関係の解消）
2.  **Close**: 相手が将来の生活に不安を感じたタイミングで、**戦略②**を提示し、具体的なメリットで決断を後押しする。

## 4. 教育用リソース

- 2つの事例をNotebookLMで比較読み込みし、「自分の担当エリアの地権者Aさんはどちらのタイプか？」をシミュレーションしてください。
